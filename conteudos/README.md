# Máquina de conteúdos

## Como usar uma transcrição

1. Coloque o arquivo em `transcricoes/entrada/`, em texto (`.txt`, `.md`, `.srt` ou `.vtt`).
2. Digite `/decompor` no Claude Code.
3. Escolha no mapa o que quer produzir.
4. Revise os rascunhos no painel e aprove.

## Pastas

- `plano/`: pautas, calendário e perguntas para testar nas IAs.
- `transcricoes/`: transcrições recebidas. Não vão para o GitHub.
- `biblioteca/`: ideias, histórias, frases e números extraídos.
- `mapas/`: propostas de conteúdo de cada transcrição.
- `pesquisas/`: resultados do `/pesquisar-pauta`.
- `pautas-quentes/`: resultados do `/pautas-quentes`.
- `radar/`: revisões mensais, auditorias, exportações e testes nas IAs.
